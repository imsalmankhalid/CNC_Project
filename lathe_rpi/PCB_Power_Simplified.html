🔗 Diode OR-ing Logic

When 12V is present:
Buck outputs 5V → D11 conducts → 5V0 rail active
5V0 rail feeds RPi Pin 2,4 (powers the Pi)
D12 is reverse-biased (RPi has no USB-C power)

When no 12V (USB-C only):
RPi USB-C powers Pi internally
RPi Pin 2 outputs 5V → D12 conducts → 5V0 rail
D11 is reverse-biased (buck has no 12V input)
HAT logic runs from RPi back-fed power ✓

⚡ Power Flow Summary

12V mode (normal):
12V → Buck → 5V0 → D11 → RPi Pin 2,4
RPi generates 3.3V internally → Pin 1 → HAT

USB-C mode (debug):
USB-C → RPi → Pin 2 → D12 → 5V0 rail
RPi → Pin 1 → 3V3 rail → HAT logic

EN pin: Tied to VIN_12V (always on when 12V present, off when absent)
